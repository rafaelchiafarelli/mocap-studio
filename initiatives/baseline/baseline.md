# baseline — mocap-studio

**Goal:** Organize the project: repository versions, per-take pipeline execution and the **camera bottleneck study**, which decides whether investing in hardware is worth it.

**Scope:** No mocap logic. Environment scripts, orchestrating CLI and the study protocol/report.

**Out of scope:** Distributed worker, database, web dashboard (phase 2).

**Initiative gate:** Study report with a recorded decision: keep the current cameras or replace which ones.
