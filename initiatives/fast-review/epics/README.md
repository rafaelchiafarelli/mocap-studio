# fast-review — epics

1. `one-command`: one command runs both bodies to one Blender file, restarts from a stage, and renders only when asked.
2. `shared-file`: every run in one file, with its nickname over the model. Its first task is a trial and can start before the first epic.

**Gate:** `fast_review.py` runs the man and the woman to one Blender file, and Rafael opens it.
