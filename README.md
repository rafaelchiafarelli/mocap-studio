# mocap-studio
Mocap studio is an environment to record, process and edit motion capture.
It creates a pipeline to capture video and process into a animation ready data.
The video is captured with 4 cameras for the body, 2 caperas for the hands and 1 camera for the face. All of those images are processed, layered and turn into bones that are transmited to animated model caracters. 
Using motion capture by image tecnology (MediaPipe)
